# Manual accessibility evidence

Production `/` was checked with keyboard navigation: skip link, theme control, navigation, and main follow reading order; focus is visible and exits normally. At 320 CSS px and browser 200% zoom, content reflows without horizontal scrolling. With reduced motion enabled, the theme action remains operable without animated transitions. Screen-reader labels announce `Tema actual: claro|oscuro` and the opposite action; the control has no pressed or switch state.
